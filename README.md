# Bot-Xp-Discord
código simples de xp para bot do discord, ainda em progresso(feito em Py).
comando já presente no bot (*status) para mostrar o seu Level e perfil salvos.
alem do código, não esqueca de pegar a pasta de imagens que contem o .png usado no codigo
o arquivo de Xp já é criado automaticamente, so colocar o Tolkien do seu Bot ou copiar as linhas de codigo do evento de Xp para seu bot ja programado e ser feliz.
codigo ainda em desenvolvimento futuramente tera mais opções e comandos.
